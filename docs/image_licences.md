# Image and Brand Asset Licences

## Placeholder policy
The current interface uses **no external image files**. Visuals are produced locally with CSS (branded gradient
hero, navigation dots, university avatar badges with initials, flat icons). This guarantees the app runs fully
offline and avoids licence issues.

## Static brand assets
- The UniGuide Uganda logo mark and colour palette (navy `#12345A`, green `#18794E`, white, light grey `#F1F5F9`,
  gold `#F4B942`) are original designs created for this project.

## If real photos are added later
Add them under `static/images/` and record licence details here. Recommended sources:

| Intended use | Preferred source | Licence |
|--------------|------------------|---------|
| University campus photos | Official university websites (own assets) | With each university's permission |
| Student / campus stock | Unsplash, Pexels | Unsplash/Pexels licence (free to use, no attribution required) |
| Logo for Makerere, Kyambogo, etc. | University press/media pages | Trademark — use only with permission |

Any third-party asset in `static/images/` MUST be listed in the table below with source and licence.
